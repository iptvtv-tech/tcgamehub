Credits & licences

The games in Play now are shared under their creators' open licences. Each one's full source code is here too, as those licences ask.

GameMade byLicenceSource code

The emulator is EmulatorJS 4.2.3 (GPL v3), running libretro cores: FCEUmm (NES), Snes9x (SNES), Gambatte (Game Boy), mGBA (GBA), Genesis Plus GX (Sega), Stella 2014 (Atari 2600) and MAME 2003-Plus (arcade). All files are served from this site. Each core's licence travels inside its file in vendor/emulatorjs/cores/. Snes9x, Genesis Plus GX and MAME 2003-Plus allow non-commercial use only, which is why this page has no ads or paid extras.

Retro Vault games aren't on the leaderboard, because scores from an emulator can't be checked. Save states stay in your browser.
